# Pietro Rodrigues — Portfolio Website

Personal portfolio website built with **HTML, CSS, and JavaScript**. The project presents professional information, academic background, portfolio projects, and contact details.

## About

This repository contains an early version of my personal developer portfolio. The website was created to practice front-end development and organize professional information into an interactive single-page experience.

## Sections

- **About me** — personal and professional introduction
- **Education** — academic background and training
- **Portfolio** — selected projects
- **Contact** — contact and social information

## Technologies

- **HTML5** — structure and content
- **CSS3** — styling and layout
- **JavaScript** — section navigation and interactions

## Project Structure

```text
Pietro/
├── Image/       # Website images
├── index.html   # Main page
├── estilos.css  # Page styles
├── meuScript.js # Interactive behavior
└── README.md
```

## Purpose

The project was developed as a practical exercise in **web development**, focusing on page structure, styling, JavaScript interactions, and portfolio presentation.

## Status

This is an older personal portfolio project. It is preserved as part of my development history and learning process.
